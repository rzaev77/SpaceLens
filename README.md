**Запускается командой python app.py из папки проекта**

**Структура:**
app.py — главное окно с вкладками «Карта диска» и «Очистка дубликатов фото», тёмная плоская тема (скругления 6–8px, Segoe UI).
core/scanner.py — сканирование в QThread через os.scandir: пропуск симлинков и Windows reparse points/junctions, обработка PermissionError/FileNotFoundError, сигналы прогресса, завершения, отмены и ошибки, отмена по кнопке.
core/treemap.py — Squarified Treemap Брюльса, итеративный (не падает на сотнях тысяч файлов), нормализация весов по площади, корректные нулевые веса.
ui/treemap_view.py — виджет на QPainter: родственные оттенки slate/indigo/teal/amber для детей одного родителя, тултипы с путём и размером (Б→КБ→МБ→ГБ), клик по папке — проваливание внутрь, хлебные крошки, правый клик — «Открыть в Проводнике» и «Удалить в корзину» с пересчётом размеров.
core/deduplicator.py — jpg/jpeg/png/webp/bmp, фильтр по размеру файла, 64-битный dHash (9×8, grayscale, Pillow), Хэмминг ≤ 4. Для поиска пережатых копий с другим размером хеш индексируется по 5 полосам — пары берутся только из совпадающих корзин, без квадратичного перебора.
ui/duplicates_view.py — карточки групп с миниатюрами, бейдж «Оригинал», кнопка «Оставить оригинал (наибольшее разрешение)», выборочное удаление чекбоксами, всё через send2trash с подтверждением.
